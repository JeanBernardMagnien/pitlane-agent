CPU % / pilote = CPU total ÷ pilotes connectés — coût CPU marginal par pilote, indépendant du nombre de pilotes. Utile pour comparer des machines ou estimer le coût d'un pilote de plus.

Répartition CPU par cœur (instant)

Un cœur au-dessus du seuil rouge (95%) est le signe d'un plafond single-core, même si le CPU total semble encore correct.
